# Project: Dynamic Input and Exception Handling

## Project Description
This project enhances my previous OOP assignments by replacing hardcoded data with dynamic user input. It allows a user to enter their Student ID at runtime, making the program interactive.

## Exceptions Implemented
- **NumberFormatException**: This ensures the program doesn't crash if a user enters letters or symbols instead of a numeric ID.
- **Try-Catch-Finally**: This logic is used to handle errors gracefully and ensure that the Scanner resource is closed properly after execution.
---
## Activity 4: Collections & File Handling
- **Collections**: Used `ArrayList` to store multiple records in memory during runtime.
- **File Handling**: Implemented `BufferedWriter` for writing data and `BufferedReader` for reading records from `students.txt`.
- **Persistence**: This ensures data is saved to a permanent file and not lost when the program ends.
